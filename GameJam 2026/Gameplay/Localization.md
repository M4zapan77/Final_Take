# Spanish and English

FINAL TAKE defaults to Spanish. The existing Settings page now has Español and English buttons alongside the existing audio controls. UStudioLanguageSubsystem.SetLanguage is Blueprint-callable; OnLanguageChanged reports successful changes. The preference is saved in Unreal's GameUserSettings.ini, survives a new movie and process restart, and never enters recording or scoring data. Editor culture/preview settings are restored after PIE.

Player-facing native text uses stable NSLOCTEXT keys and FText formatting. Known cosmetic names resolve from stable cosmetic IDs, independently of widget order or outfits. The old Spanish-only widget translation dictionaries were removed. Existing FText instances (roles, awards, objectives and cosmetic names) update when the language changes; the game does not restart.

Author translations in Config/Localization/FinalTakeTranslations.json. Keys can be English source text, or a namespace/key context such as CosmeticNames,Brows.Angry. Run Scripts/Build-Localization.ps1 after editing text. It gathers the native source, exports Unreal PO files, fills reviewed translations and compiles Content/Localization/FinalTake/{en,es}/FinalTake.locres plus metadata. The generated PO/archive/manifest files are retained for editing and audit. DefaultGame.ini stages both cultures with the EFIGS internationalization data. New editable UMG text can use the same namespaces or the project's localization target. Audio/voices and baked text inside videos/textures are not automatically translated.

Validation: 289 gathered text entries covered in Spanish, zero missing translations and no localization conflicts. Development Editor build passed. All 63 automated tests passed, including changing the same existing role/cosmetic/rating FText between languages. A native six-turn police recovery movie passed, changed results from Spanish to English without changing its score or ownership, replayed the movie, and started another movie in English. A separate process restored saved English, switched back using the actual Settings buttons, saved Spanish, and preserved the HUB media player and menu navigation. Screenshots and JSON evidence are under M5. Final Shipping culture inclusion and performance remain later checks.

The menu test exposed repeated skip requests restarting the intro fade. SkipIntroductions is now idempotent while already fading to the HUB. Compilation staging also now timestamps changed source files when applied, preventing a newer object file built from the previous source from being incorrectly reused.
